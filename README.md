# Static Safety Solutions

Company website for **Static Safety Solutions** — ESD protection, static-control products and industrial safety solutions for electronics manufacturing.

## About the site

A clean, responsive, single-page website built with plain HTML, CSS and JavaScript (no frameworks, no build step):

- **Product catalogue** — 29 products across 7 categories (ESD Protection, ESD Apparel, ESD Furniture, Mats & Flooring, Testing Equipment, ESD Storage, Packaging & Consumables) with category filters and live search
- **Product cards** — real product photos, short descriptions, key highlights and "Enquire Now" buttons
- **Product details modal** — image, category, description and feature list per product
- **Enquiries via WhatsApp** — every enquiry button and the contact form opens WhatsApp with a pre-filled message to the company number
- **Solutions, Industries, About and Contact sections** — company information, service approach and full contact details

## Structure

```
index.html          Single-page site
styles.css          All styles (clean, maintainable, responsive)
script.js           Navigation, filtering, search, modal, WhatsApp, reveal
brand-mark.svg      Logo / favicon
robots.txt          Search engine rules
assets/products/    Product images
  *.svg             Line-art illustrations (epoxy flooring, workstation, etc.)
  photos/*.jpg      Real product photos (cropped from the company product sheet)
```

## GitHub Pages

The site works as a static site at the repository root. To publish:

1. Push the repository to GitHub (`prashanthireddygopu-lab/Static-Safety-Solutions`).
2. In the repository settings, enable **GitHub Pages** with **Deploy from a branch** → `main` / root.
3. The site will be available at `https://prashanthireddygopu-lab.github.io/Static-Safety-Solutions/`.
